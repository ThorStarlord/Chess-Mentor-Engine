# Research

This directory holds product, pedagogy, model, and architecture experiments. It should contain evidence from discovery work, not invented results.

The [first product-validation experiment](first-product-validation/README.md) is currently designed and frozen, but not executed. Product validation should precede domain modeling for the recurring-player-diagnosis thesis.

No participant material or results are currently present. The experiment's operational intake and data-handling documents are ready for a real Run 1 package.

Each meaningful experiment should eventually record:

- question;
- hypothesis;
- method;
- evidence;
- result;
- limitations;
- decision impact.

Likely research areas include:

- learner segmentation;
- game-derived misconception detection;
- engine-analysis interpretation;
- pedagogical explanation quality;
- longitudinal player modeling;
- curriculum selection;
- transfer measurement;
- mastery criteria;
- human comprehension and trust;
- LLM versus deterministic responsibility boundaries.

Do not create fake experiments or placeholder result files.
