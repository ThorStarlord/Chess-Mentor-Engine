# First product-validation experiment

Status: Protocol designed and frozen. Participant execution has not been performed.

This directory defines the first manual or semi-manual test of the Chess Mentor Engine product claim. It tests whether an evidence-backed recurring decision-pattern diagnosis gives a player a better basis for choosing what to practice than a competent conventional game review.

The study is product discovery, not a representative research study. It does not validate a chess-analysis implementation, a learner model, rating improvement, or a complete tutoring system.

## Artifacts

- [Protocol](protocol.md) is the authoritative frozen methodology.
- [Participant criteria](participant-criteria.md) defines the intended sample and game-set requirements.
- [Analyst guide](analyst-guide.md) defines manual analysis rules and bias controls.
- [Analysis template](analysis-template.md) provides one reusable report structure per participant.
- [Participant evaluation](participant-evaluation.md) contains the blinded comparison questionnaire.
- [Synthesis plan](synthesis-plan.md) defines how evidence will be interpreted without collapsing it into one score.
- [Experiment manifest](experiment-manifest.md) records the planned run and later deviations.
- [Execution runbook](execution-runbook.md) defines the operational steps needed to begin Run 1.
- [Participant intake](participant-intake.md) captures the minimum eligibility and game-set metadata.
- [Data handling](data-handling.md) defines privacy and provenance rules for real participant material.
