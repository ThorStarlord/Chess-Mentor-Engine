# FPV-PILOT-003

Status: DESIGNED AND FROZEN — NOT EXECUTED.

Title: Player Decision Evidence Instrument Calibration

Pilot 003 follows the mixed, participant-specific result of [Pilot 002](../FPV-PILOT-002/result.md). Pilot 002 showed that direct player evidence adds information beyond chess evidence and board context, while also showing that spontaneous responses can be authentic but sparse.

Pilot 003 tests the measurement instrument before any multi-participant replication. It separates spontaneous reasoning from standardized neutral probing and measures whether the probe itself changes the participant's decision.
