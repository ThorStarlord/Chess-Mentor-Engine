# Pilot 004 batch protocol

For each batch:

1. freeze the eligible game pool and source provenance;
2. audit every candidate position as FRESH, EXPOSED, or UNCERTAIN;
3. select 8–10 balanced positions under the frozen rules;
4. freeze IDs, FENs, provenance, exposure, and internal rationale;
5. present Position Context only;
6. collect A1 using the minimal prompt and freeze it;
7. collect the standardized A2 probe and freeze it;
8. reveal objective chess evidence only afterward;
9. record probe effects, discrepancies, controls, contradictions, and uncertainties;
10. write a bounded batch record before carrying hypotheses forward.

Do not select positions after seeing P01 responses, dynamically alter questions, or treat a changed decision as invalid by itself.
