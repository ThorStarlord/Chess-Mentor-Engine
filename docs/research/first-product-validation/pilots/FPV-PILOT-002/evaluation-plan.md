# Pilot 002 evaluation plan

Status: Evaluation plan frozen. Pilot 002 has not been executed.

Compare C1, C2, and C3 without collapsing the result into one weighted score.

## Task-level dimensions

Assess separately whether each condition supports:

- understanding the board;
- explaining why the played move is bad;
- comparing candidate moves;
- identifying an observable decision pattern;
- distinguishing competing learner-level explanations;
- recommending a bounded intervention.

## Participant dimensions

Where P01 can evaluate the material, record:

- comprehension;
- evidence traceability;
- trust;
- specificity;
- actionability;
- usefulness for choosing what to practice;
- what remained unclear;
- whether the explanation changed after board context or player reasoning was added.

## Researcher and reviewer dimensions

Record whether:

- the board representation is accurate and understandable;
- claims trace to the packet and source game;
- player decision evidence is labeled separately;
- competing explanations are genuinely distinguishable;
- the diagnosis exceeds the evidence;
- the intervention follows from the evidence;
- richer context adds useful information or only more text;
- analysts can reproduce the distinction between C1, C2, and C3.

## Interpretation

H1 is supported only if C2 improves board and move explanation over C1. H2 is supported if C2 improves explanation but learner-level cause remains ambiguous. H3 is supported only if C3 adds decision evidence that changes or narrows competing explanations. H4 is supported if added context does not materially improve these dimensions relative to its collection and interpretation cost.

These are qualitative research judgments, not statistical thresholds.
