# external-evidence-packet

Use when a repository/strategic decision depends on facts from an authorized
external source.

Produce:

`artifacts/external_evidence_packet.md`

## Procedure

1. State the exact decision/question the evidence bears on.
2. Use only authorized external access surfaces.
3. Record each source's stable identifier/URI, title/publisher when known, and
   retrieval time.
4. Record only claims actually supported by the sources.
5. Bind each claim to one or more source IDs.
6. State currentness/expiry limitations when the fact can change.
7. Do not treat the packet as repository fact, timeless truth, or authority.
8. Validate the finished packet.

```text
external evidence != repository evidence
retrieved source != timeless claim
valid provenance != semantic truth
```
