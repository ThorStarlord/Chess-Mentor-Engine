# Interview synthesis

Satisfy a `research_synthesis` responsibility by producing `synthesis_report` from supplied interview evidence.

## Inputs

Require one or more identifiable interview sources plus the research context or question. Multiple interviews improve cross-respondent pattern analysis, but never invent extra respondents to meet a preferred sample size.

## Procedure

1. Read [references/methodology.md](references/methodology.md).
2. Assign or retain a stable source reference for every interview.
3. Extract candidate jobs, pains, gains, behaviors, alternatives, triggers, and direct quotes per source.
4. Cluster only patterns supported by supplied sources. Preserve meaningful contradictions and outliers.
5. Count frequency only from the actual supplied set.
6. Rank problems only when ranking dimensions are supportable; label agent-estimated severity separately from measured frequency.
7. Separate findings from recommendations and next research.
8. Render [references/output-contract.md](references/output-contract.md) and return control.

## Stop or reject

- If there is no actual interview evidence, do not manufacture a synthesis report; surface the missing input.
- Never invent respondents, quotes, frequencies, or source support.
- If source identity is too ambiguous to support traceability, request or derive stable local labels without fabricating provenance.

## Boundary

`source traceability != finding truth`, and `pattern frequency != strategic importance`.
