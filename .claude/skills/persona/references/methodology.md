# Persona methodology

Adapted from `lucasgaravelli/pm-skills-claude-code/.claude/commands/persona.md` at commit `21cbb2903d740d10fc65c667aea97d3ee8657349` (MIT, Flowgrammers 2026).

Use Jobs to Be Done as the organizing frame: functional job (`When [situation], I want [action], so I can [outcome]`), secondary jobs, emotional outcomes, and social outcomes. Cover only decision-relevant profile attributes such as role/context, workflows, pains, desired outcomes, current alternatives, evaluation criteria, decision influences, objections, and success measures.

Prefer real supplied evidence. Record confidence as `high`, `medium`, or `low` from the evidence available for each material section, not from how plausible the prose sounds. Rank pains only when ranking inputs exist or the ranking is explicitly an agent estimate. Quotes from real interviews must remain distinguishable from inferred illustrative voice; never manufacture a quote and label it real.

End by identifying low-confidence assumptions and the smallest research that would materially change the persona.
