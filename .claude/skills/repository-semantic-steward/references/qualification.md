# Qualification — What this Skill can and cannot claim

Evidence levels are separate:

1. **Mechanical:** Skill entrypoint loads, references resolve, schemas validate, committed snapshots rebuild, source audit and queries behave predictably.
2. **Semantic:** A source-inspecting reviewer confirms a subset of authored concepts, decisions and implementation edges; record contradictions and uncertainty.
3. **Practical:** A genuine agent uses the knowledge in useful authorized engineering; record decisions and outcome, not merely invocation.
4. **Longitudinal:** A **fresh, independent** coding-agent context uses or corrects knowledge from an earlier episode. New Python process, synthetic roleplay or same-conversation replay is not sufficient.
5. **Comparative:** Evidence supports reduced rediscovery/rework or better decisions against a credible alternative, with honest confounds. Correct retrieval or increasing index counts alone is not comparative improvement.
6. **Transfer:** The process works on a second product with different repository conventions without special-case scaffolding overwhelming the value.
