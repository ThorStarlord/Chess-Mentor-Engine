# Guided Entry v1

Use this reference when a human knows the kind of problem they have but does not
want to learn the entire Sensemaking architecture first.

The canonical static mapping is exposed by:

`bash
sensemaking-skills journey guide --intent <intent>
`

| Intent | Existing capability |
| --- | --- |
| `repository-future` | strategic-repository-analysis |
| `responsibility-unclear` | using-sensemaking + repo-sensemaker |
| `selected-work` | Campaign / execution handoff |
| `returned-work` | Learning / Reconciliation |
| `repository-changed` | Strategic Continuity |
| `change-consequences` | change-impact-analysis |
| `multi-repo-boundary` | multi-repository-strategic-analysis |

This reference is guidance only.

`
human chooses intent
-> tool explains a fitting existing capability
-> human/agent still owns semantic selection
`

It is not an automatic router and does not invoke a Skill.
